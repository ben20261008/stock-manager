手續費與交易設定

預設值僅供估算，請依國泰證券實際網路下單費率、個人折扣與交易商品調整。台股股票一般賣出證交稅常見為 3‰，ETF 等商品可能不同。

自動停損／停利提醒

設定在持股中的停損價與目標價後，系統會在更新行情時自動檢查，並在本頁開啟期間每 3 分鐘嘗試檢查一次。可開啟瀏覽器通知。網頁關閉、裝置休眠、行情來源失效時無法保證持續監控；不會自動下單。

尚未檢查

資料備份／還原

資料存在這台裝置的瀏覽器中。換手機、平板或電腦不會自動同步，請定期匯出備份，再於另一裝置匯入。

行情與風險說明

本程式不是券商下單系統，也不連結國泰證券帳戶。公開行情端點可能延遲、限流或變更，畫面會標示行情取得狀態。AI／條件分析僅供研究，不構成投資建議；進場前請自行確認成交量、公告、財報、交易成本與風險承受度。

若要真正的即時行情與雲端 AI 分析，需要選定合法行情 API／服務並設定 API 金鑰；不要把私人金鑰直接放進公開 GitHub 網頁。
